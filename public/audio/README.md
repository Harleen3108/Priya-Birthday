# Audio Assets

Place your birthday song here:

```
public/audio/birthday-song.mp3
```

**Requirements:**
- MP3 format (Howler supports MP3, OGG, WAV)
- Licensed/owned by you (no copyrighted music without permission)
- Recommended: 30–90 seconds, looping-friendly

The song plays after the user taps to open the birthday card (required for browser autoplay policy).
